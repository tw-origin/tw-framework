# TW Framework — i18n

This document covers one thing completely: `@tw/runtime` internationalization — translating strings, plurals, and locale-aware formatting.

---

## Initializing

```twm
import { initI18n } from "@tw/runtime"

const i18n = initI18n({
  defaultLocale: "en",
  fallbackLocale: "en",
  messages: {
    en: { greeting: "Hello", cart: "Your cart has {count} items" },
    hi: { greeting: "Namaste", cart: "Aapke cart me {count} cheezein hain" }
  },
  warnOnMissing: true
})
```

## Translating

```twm
import { t } from "@tw/runtime"

t("greeting")                          // "Hello"
t("cart", { count: 3 })               // "Your cart has 3 items"
```

`t(key, params)` substitutes `{name}` placeholders from the params object.

## Plurals

`tn` picks the plural form by count:

```twm
import { tn } from "@tw/runtime"

tn("items", 1)   // "1 item"
tn("items", 5)   // "5 items"
```

## Changing Locale

```twm
import { setLocale, getLocale } from "@tw/runtime"

setLocale("hi")
getLocale()    // "hi"
t("greeting")  // "Namaste"
```

## Locale-Aware Formatting

Lazy loading of extra locales is built in — pass `lazyLoad(locale)` returning a promise of that locale's messages, and the runtime fetches a locale on first use.

| Option | Meaning |
|--------|---------|
| `defaultLocale` | the starting locale |
| `fallbackLocale` | used when a key is missing |
| `messages` | locale to flat key/string map |
| `lazyLoad` | load a locale on demand |
| `warnOnMissing` | log missing keys (dev) |
| `cacheSize` | compiled-message cache bound |

## Locale-Aware Formatting

| Function | Formats |
|----------|---------|
| `formatNumber(value, options?)` | 1,234 vs 1.234 by locale |
| `formatCurrency(value, currency)` | "₹1,500" vs "$1,500" |
| `formatDate(date, options?)` | dates per locale calendar |
| `formatRelativeTime` | "5 minutes ago" |
| `formatList` | "a, b and c" joining rules |

All of these ride the standard `Intl` APIs with the active locale.

## Direction

```twm
import { isRTL, getTextDirection } from "@tw/runtime"

isRTL()               // true for RTL locales
getTextDirection()    // "rtl" | "ltr"
```

Set `dir` on your layout from `getTextDirection()` so RTL locales mirror the page.
