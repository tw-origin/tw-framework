# Examples

Ready-to-run TW Framework projects. Each folder is a complete app.

| Example | What it shows |
|---------|---------------|
| [`hello-tw`](./hello-tw) | The default scaffold — pages, styling, layout, a route handler |
| [`tw-blog`](./tw-blog) | A blog starter — dynamic routes, post pages, server rendering |

Run any of them:

```bash
cd hello-tw
npm install
npm run dev
```

More guides live in [docs/](../docs) — and `npx create-tw-app@latest my-app --template blog` scaffolds the blog starter directly.
