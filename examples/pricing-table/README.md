# Pricing Table -- A Static Page Done Properly

Three tiers, a feature matrix, and an FAQ -- the classic static pricing
page, in pure TSS grid. Zero JavaScript.

## What it teaches

- A production-shaped static page (pricing) with real content structure
- TSS grid + responsive columns
- render static for content that is exactly the same for everyone

```sh
tw build && tw serve --port 8123 & sleep 2
# open http://127.0.0.1:8123/
```
